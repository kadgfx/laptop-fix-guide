# Laptop Fix Guide — PWA

Static web version for GitHub Pages.

## Deploy
1. Create a GitHub repo
2. Upload the contents of this folder
3. Settings → Pages → Deploy from branch (main / root)
4. Open `https://USERNAME.github.io/REPO/`

On iOS: open in Safari → Share → Add to Home Screen.

## Update
Când urci o versiune nouă, crește `VERSION` în `sw.js` (ex. `2`, `3`...).
Utilizatorii vor primi actualizarea automat la următoarea vizită.
